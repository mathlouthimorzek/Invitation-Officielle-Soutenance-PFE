# 🎓 Invitation Numérique - Soutenance de PFE

Ce dépôt contient le code source d'une invitation numérique interactive et moderne pour ma soutenance de Projet de Fin d'Études (PFE). L'application intègre un design épuré, un système de géolocalisation pour le lieu de l'événement et un compte à rebours dynamique en temps réel.

* **Institution :** Institut Supérieur des Études Technologiques de Sfax (ISET Sfax)

## 🛠️ Technologies Utilisées

Ce projet a été développé de manière minimaliste et performante sans framework lourd, afin de garantir un chargement instantané sur mobile et ordinateur :

* **HTML5** : Structuration sémantique de la carte d'invitation.
* **CSS3** : Design responsive (Flexbox/Grid), typographie moderne (Google Fonts - Montserrat) et animations fluides au survol.
* **JavaScript (Vanilla)** : 
  * Algorithme de calcul du compte à rebours dynamique mis à jour à chaque seconde.
  * Interaction avec l'API Google Maps pour la localisation de l'établissement.
